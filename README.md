# VulnStore

A deliberately vulnerable e-commerce application built for learning:

- Application Security
- Secure SDLC
- DevSecOps
- Threat Modeling
- OWASP Top 10
- OWASP API Top 10

## Tech Stack

- Node.js
- Express
- SQLite

## Learning Objectives

- Build vulnerable features
- Exploit vulnerabilities
- Fix vulnerabilities
- Implement security controls
- Integrate DevSecOps pipelines
